# Nudge — UX principles

These are **working product/UX principles** for future proposals, not proof that any specific screen already follows them.

## 1. Mobile is primary

Design and validate the smallest practical view first: clear navigation, legible content, sufficient touch targets, visible progress, and low-friction actions. Desktop can adapt but should not dictate learning flows.

## 2. Learning by doing

A strong interaction follows **concept → scenario → decision → explanation → next step**. Give meaningful feedback on trade-offs and reasoning, not just whether a tap was "right".

## 3. Accessible, not childish

Use straightforward language and focused interactions. Avoid dense finance jargon, visual noise, and gimmicky gamification. Financial confidence should come from understanding rather than simulated winnings.

## 4. One clear primary action

Each screen should communicate its purpose and next step. Use Violet for main calls to action; Gold for educational support; Teal for selective progress highlights. Keep success/error/warning states semantically separate.

## 5. Meaningful feedback

Selection, correctness, progress, loading, disabled and error are distinct states. Explain results with text; never depend on colour alone. Use readable labels, visible keyboard focus and adequate contrast.

## 6. Gamification in service of learning

Progress and streak-like ideas are optional hypotheses. Any mechanic should reinforce retention and comprehension, not push users toward excessive or impulsive financial decisions.

## How to apply these principles

Before changing UX: inspect actual user flows and reusable components; identify the learner's problem; make the smallest useful proposal; check mobile and accessibility; document proposed deviations. Do not change identity or sensitive infrastructure without authorization.
