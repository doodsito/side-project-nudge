# Mascotte : un teammate discret

Le pack fourni est conservé sans retouche. Rose réservé à la mascotte ; palette C pour l’interface.
- Curiosité : près des repères d’apprentissage, sans suggérer une bonne réponse.
- Encouragement : près de l’explication du produit, sans féliciter un résultat financier.
- Accueil : petit format dans la fenêtre de liste d’attente.
- Pas de bulles impératives, de tutoriel guidé, de culpabilisation, ni d’animation permanente.
- Images décoratives avec texte adjacent, proportions préservées, WebP et dimensions réservées.
- Cette première application reste sur la landing. Le déploiement dans les leçons sera validé séparément.
