# Northpath homepage redesign

## Goal
Rebuild the homepage into a clear, conversion-focused story for first-time investors while preserving the Northpath identity and the working `/demo` experience.

## What will change
- Replace the current homepage composition with the selected sophisticated product-led direction.
- Keep Northpath’s existing wordmark treatment, warm off-white surfaces, indigo primary, mint accents, Manrope headings, and Inter body copy.
- Use one consistent primary action: **Join the beta**.
- Add a polished email-first beta modal with an optional learner-profile step and confirmation.
- Add the requested compact navigation and a subtle `/universities` placeholder page.
- Make the product visible immediately through the existing educational challenge preview, adapted to the selected visual direction.
- Rebuild the page in this order: outcome-led hero, information-overload problem, before/after transformation, four value propositions, real-market reasoning, three-step method, interactive challenge, adaptive learning, objective alternatives comparison, early-access invitation, long-term outcome, FAQ, final action, footer.
- Keep all claims educational and clearly distinguish simulations from investment advice.
- Add the named analytics hooks without adding an analytics service.
- Add route-specific metadata, FAQ structured data, and semantic heading structure.

## Interaction details
- The interactive challenge will work directly on the homepage and provide educational feedback after a selection.
- All **Join the beta** actions will open the modal; the existing `/demo` will remain accessible as the hands-on product preview.
- Mobile navigation, modal focus behavior, keyboard controls, touch targets, visible focus states, and reduced-motion behavior will be included.

## Verification
- Check every homepage action, challenge answer, modal step, and navigation destination.
- Test desktop, tablet, standard phone, and small phone layouts for readability and horizontal overflow.
- Confirm `/demo` still works and the project finishes with no build or runtime errors.
